# FoodExpress frontend (Angular 20)

Complete project: open this folder in VS Code, then in the terminal:

    npm install
    npm start

Open http://localhost:4200. The Spring Boot backend must be running on port 8080.
Backend URL: src/app/core/config.ts

Demo logins: customer@demo.com / owner@demo.com / rider@demo.com (password Demo@1234),
admin@fooddelivery.com (password Admin@12345).
